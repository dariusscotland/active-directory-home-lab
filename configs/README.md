# Configuration Notes

Store only safe examples and documentation here. Do not commit credentials, private keys, exported VM files, real user data, or full configuration dumps containing sensitive information.

Recommended files to add after you build the lab:

- `network-plan.md` — actual lab subnet, server IP, DHCP range, gateway, and DNS.
- `domain-plan.md` — lab domain and OU structure.
- `sample-users.csv` — synthetic names only, if you later choose a CSV-driven workflow.

Redact identifying details before publishing screenshots or command output.
